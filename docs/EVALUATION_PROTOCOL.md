# MathLab Learning Evaluation Protocol

## Research question

Intuitsiya → qog‘ozdagi yechim → vizualizatsiya → hisoblash → tekshiruv oqimi oddiy statik materialga nisbatan universitet talabasining tushunishi va masala yechish natijasini yaxshilaydimi?

## Pilot

1. Ikki taqqoslanadigan guruh yoki random split.
2. Bir xil 10–15 daqiqalik pre-test.
3. Bir xil mavzu va teng vaqt.
4. Control: oddiy konspekt/darslik.
5. MathLab: interaktiv laboratoriya.
6. Bir xil post-test.
7. 7 kundan keyin delayed test.

## Primary metrics

- to‘g‘ri javob foizi
- yechimni yakunlash darajasi
- o‘rtacha yechish vaqti
- protseduraviy xatolar
- konseptual tushuntirish balli
- 7 kunlik retention

## Secondary metrics

- kerak bo‘lgan hintlar soni
- metod tanlash aniqligi
- oldin/keyin confidence
- usability
- talaba izohlari

## Scientific value

Software — intervention. O‘lchangan learning improvement — research contribution.

Pilot → dataset → statistik tahlil → konferensiya → maqola.

Matematik fizika tenglamalari

Tenglamani klassifikatsiya → fizik ma’no → qog‘ozdagi yechim → animatsiya → tajriba zanjirida ko‘ring.

UMUMIY KO‘RINISH

A uₓₓ + 2B uₓᵧ + C uᵧᵧ + ... = 0

MEZON

D = B² − AC

MA’NO

D<0 elliptik, D=0 parabolik, D>0 giperbolik.

Koeffitsiyentlarni kiriting

Qog‘ozda:
  1. A, B, C ni ajrating.
  2. D=B²−AC ni hisoblang.
  3. D ishorasiga qarab turini yozing.

Natija

ElliptikmuvozanatLaplace, Poisson
ParabolikdiffuziyaIssiqlik
Giperbolikto‘lqinWave equation
MODEL

uₜ = αuₓₓ

HAYOTIY MA’NO

Issiqlik yuqori temperaturadan past temperaturaga tarqaladi.

QOG‘OZDA

Ajratish usuli: u=X(x)T(t) → eigenvalue masala → Fourier qatori.

Sterjen tajribasi

Qog‘ozdagi g‘oya:
  1. u(x,t)=X(x)T(t).
  2. X″/X = T′/(αT) = −λ.
  3. X uchun sinus eigenfunksiyalar.
  4. T da e^(−αλt) so‘nish.
  5. Boshlang‘ich profil Fourier koeffitsiyentlarga ajraladi.

Temperatura profili

MODEL

uₜₜ = c²uₓₓ

HAYOTIY MA’NO

Tor, tovush, elastik muhitdagi tebranishlar.

MUHIM FARQ

Issiqlik so‘nadi; ideal to‘lqin energiyani oldinga-orqaga tashiydi.

Tor parametrlar

Qog‘ozda:
  1. u=X(x)T(t).
  2. X″+λX=0.
  3. Mahkamlangan uchlar → Xₙ=sin(nπx).
  4. Tₙ=A cos(nπct)+B sin(nπct).

Tor tebranishi

MODEL

uₓₓ + uᵧᵧ = 0

HAYOTIY MA’NO

Barqaror temperatura yoki elektrostatik potensial.

DISKRET G‘OYA

Ichki nuqta to‘rtta qo‘shnisining o‘rtachasi.

Chegaralar

Qog‘ozda: uᵢⱼ=(uᵢ₋₁ⱼ+uᵢ₊₁ⱼ+uᵢⱼ₋₁+uᵢⱼ₊₁)/4 formulani ichki tugunlarda qayta-qayta ishlating.

Potensial / temperatura xaritasi

ERKIN PROFIL

Issiqlik tenglamasi uchun boshlang‘ich u(x,0) ni formula bilan kiriting.

ERKIN CHEGARA

u(0,t) va u(1,t) qiymatlarini o‘zingiz belgilang.

FINITE DIFFERENCE

uᵢⁿ⁺¹ = uᵢⁿ + r(uᵢ₋₁ⁿ−2uᵢⁿ+uᵢ₊₁ⁿ).

1D issiqlik sandbox

Barqarorlik: explicit sxema uchun r=αΔt/Δx² ≤ 1/2 bo‘lishi kerak. NumLab Δt ni shu shartga mos tanlaydi.
